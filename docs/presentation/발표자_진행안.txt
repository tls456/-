8~13장은 장애 대응 및 질문용 부록이며 본 발표에서 모두 읽지 않습니다.
각 슬라이드의 발표자 노트에도 대본과 설명을 넣었습니다.

1장 15초 | 소개
“성적표 한 장에서 시작해, 졸업까지 무엇을 얼마나 듣고 어느 정도의 성적을 받아야 하는지 연결해 주는 서비스입니다.”

2장 35초 | 문제와 주제
“요람의 기준, 성적표의 기록, 목표 성적 계산이 따로 떨어져 있습니다. 수강신청 전 졸업 계획을 세우는 하루를 바꾸고자 했습니다.”
사용자 조사나 시간 단축 수치는 측정하지 않았으므로 주장하지 않습니다.

3장 35초 | 해결 방식
“학번 → PDF → 목표 평점 → 대시보드입니다. 남은 총학점, 부족한 영역, 필요한 평균평점을 먼저 보여 줍니다.”

4장 45초 | 구현과 차별성
“PDF.js로 추출하고 학기·학수번호로 시간표를 매칭합니다. 공식 요람 기준과 규칙 기반 계산을 연결합니다. 자료가 불확실하면 사용자 확인을 받습니다.”
AI는 개발 보조(Codex)에 활용했으며 실행 중 생성형 AI를 호출하지 않습니다.

5장 90초 | 라이브 시연
시연 준비:
  1. ./start.sh 또는 corepack pnpm dev로 앱을 실행합니다.
  2. 새 시크릿 창에서 http://localhost:5173을 엽니다.
     기존 사용자 기록을 지우지 말고 시연을 독립된 창에서 진행합니다.
  3. docs/demo/가상성적표_2025학번.pdf를 파일 선택창에서 바로 찾을 수 있게 준비합니다.
  4. 브라우저와 PowerPoint를 미리 열어 둡니다.

실행 순서:
  ① 학번 202599999 → 교육과정 찾기 → 나의 졸업 계획 시작.
  ② PDF 선택 → 27과목, 취득 58학점, 등록 4학기 자동 입력 확인.
  ③ 확인한 성적 반영 → 목표 최종 평균평점 3.50 → 계산.
     현재 평균 3.18, 남은 74학점, 앞으로 필요한 평균 3.737 확인.
  ④ 학기별 계획 → 5개 학기·74/74, 18·18·18·18·2 배분 확인.
  ⑤ 이수 과목 · 삭제 → F 등급인 가상 과목을 삭제 대상으로 선택.
     대시보드 → 현재 평점 3.18 → 3.36, 남은 학점 74 → 74 확인.
  ⑥ PPT 6장으로 복귀.

중요:
  - “삭제”는 학점포기 시뮬레이션이며 학교 기록을 실제로 변경하지 않습니다.
  - F는 원래 취득학점이 0이라 남은 졸업학점은 증가하지 않습니다.
  - 취득학점이 있는 과목을 포기하면 남은 졸업학점은 증가합니다.
  - 가상 계획은 평점/총량 계산용 초안이며 전공·교양·필수요건을 자동 충족하지 않습니다.
  - 네트워크가 없어도 이미 실행 중인 로컬 앱에서 시연할 수 있습니다.
    최초 개발 의존성 설치는 별도 필요합니다.
  - 장애 시 5장의 “시연 백업으로 이동” 링크 또는 8~11장으로 전환합니다.
    백업은 현재 코드와 같은 가상 PDF로 캡처한 실제 화면입니다.

“현재 코드로 단위·통합 209개, 브라우저 14개, 시간표 가져오기 8개 테스트를 통과했습니다. 타입 검사와 빌드도 확인했습니다.”
React, TypeScript, Vite, PDF.js, Lucide, Vitest, Playwright와 학교 공식 자료·시간표 사용을 공개합니다.

7장 15초 | 효과·확장·마무리
“성적표를 옮겨 적고 여러 자료를 대조하는 부담을 줄이는 도구입니다. 앞으로 스캔 PDF와 실제 개설 과목을 연결하겠습니다. 감사합니다.”
7장에서 본 발표를 마치고 질의응답을 받습니다.

자주 받을 수 있는 질문
Q. 필요한 평균 3.737은 어떻게 나왔나요?
A. 현재 평점학점 54, 성적 기여 합 171.5, 미래 평점학점 74입니다.
   (3.50 × (54+74) − 171.5) ÷ 74 = 3.736486…이며 최소 필요값을 셋째 자리 올림합니다. 12장 참조.

Q. 취득 58인데 계산에는 왜 54가 들어가나요?
A. P/N은 평점에서 제외하며 F는 평점 분모에 포함합니다. 취득학점과 평점학점을 별도로 집계합니다.

Q. 다른 학과 학생도 사용할 수 있나요?
A. 지금은 2020~2026학번이며 컴공이 원전공 또는 복수전공에 포함된 GLOCAL 내 조합이 범위입니다.
   편입·전과·복수전공의 불명확한 인정 정보는 학교에서 확인한 개인 요건을 추가 입력합니다.

Q. PDF에 등록학기 수가 없으면요?
A. 등장한 서로 다른 정규학기 수 + 1을 기본값으로 제시합니다. 계절학기는 제외하고 사용자가 수정합니다.
   PDF에 등록학기 수가 명시되어 있으면 해당 값을 우선 사용합니다.

Q. AI 서비스인가요?
A. Codex를 개발 보조에 사용했습니다. 앱은 생성형 AI를 호출하지 않고 공식 출처 기반 규칙과 산식으로 계산합니다.

Q. 예측 정확도를 보증하나요?
A. 학교가 인증한 졸업 판정이 아닙니다. 학교 확인이 필요한 필수과목 인정·졸업작품 등은 별도로 안내합니다.
   테스트는 구현 검증이며 공식 규정 데이터 전체의 무오류를 인증하지 않습니다.

Q. 최저·최고 예상은 졸업 가능한 평점 범위인가요?
A. 아닙니다. 고정 학기 목표는 유지하고 미고정 평점 과목에 F 또는 A+를 적용한 이론적 누적평점 범위입니다.

제출/운영 확인
  - PPTX는 텍스트·도형이 편집 가능합니다. 글꼴은 Windows 기본 맑은 고딕입니다.
  - PDF는 같은 내용·배치로 생성한 글꼴 포함 대체본입니다.
  - PPTX와 PDF의 앱 캡처는 모두 가상 성적이며 실제 학생 자료는 포함하지 않습니다.
  - 실제 PowerPoint에서 파일 열기, 글꼴, 링크와 화면 전환은 발표 직전에 한 번 확인해 주세요.
  - 공식 개발 시간 19:30~11:30 준수 여부와 제출 마감은 팀에서 확인해야 합니다.
  - 이 작업에서 GitHub push는 하지 않았습니다.
